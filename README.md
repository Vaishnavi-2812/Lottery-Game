# Lottery-Game

🎲 Lottery Game — Java + Web Version

A simple and fun Lottery Game built using Java (console) and HTML/CSS/JavaScript (web version).
The player guesses a number, and the program generates a random number to check if the user wins.

🚀 Features

User guesses a number between 1 to 10

Computer generates a random number

Displays WIN or LOSE message

Clean UI (HTML/CSS version)

Simple logic (Java console version)

Beginner-friendly project

Perfect for GitHub & portfolio


🎯 How It Works

User enters a number from 1 to 10

JavaScript generates a random number

Compares both numbers

Displays result (“You WIN!” or “You lost!”)
